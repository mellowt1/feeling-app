# Feeling

A private, chronological record of how you have been doing. Installable on iPhone, works offline, no account, no AI.

All entries stay in the phone's local storage. Only if you join a circle does anything leave it: your mood faces for the last 30 days, a first name, a random device id, your place and an optional few-word status go to the feeling-circle Worker, which also sends the circle's check-ins and cheers as notifications. Entry text never leaves the phone. This repository holds only the app code.
